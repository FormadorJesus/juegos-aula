Cómo conectar tus juegos

Cualquier juego del repositorio (o alojado en otra web) puede solicitar ejercicios o lotes completos de 4 opciones indicando tema, nivel y tipo, o bien heredar la configuración activa que el profesor haya fijado en el aula.

1. Conexión rápida con 1 script (recomendada)

<script src="../banco_ejercicios/client.js"></script>
<script>
  async function nuevaPregunta() {
    const ej = await BancoMathClient.solicitarEjercicio({
      tema: 'ecuaciones',     // 'enteros' | 'fracciones' | 'potencias' | 'ecuaciones' | 'funciones' | 'mixto'
      nivel: '3eso',          // '1eso' | '2eso' | '3eso' | '4eso' | '1bach' | '2bach'
      tipo: 'problema'        // 'operacion' | 'problema' | 'mixto'
    });
    console.log(ej.enunciado, ej.opciones, ej.indiceCorrecto);
  }
</script>

2. Pedir un lote usando la configuración activa del profesor

const lote = await BancoMathClient.solicitarLote({
  usarConfiguracionAula: true,
  cantidad: 10,
  origen: 'MiJuegoDeAula'
});

3. Conexión remota directa por iframe + postMessage

const frame = document.createElement('iframe');
frame.src = '../banco_ejercicios/index.html?modo=api';
frame.style.display = 'none';
document.body.appendChild(frame);

window.addEventListener('message', (ev) => {
  if (ev.data?.type === 'BANCO_MATH_READY') {
    frame.contentWindow.postMessage({
      type: 'BANCO_MATH_REQUEST',
      requestId: 'peticion-1',
      action: 'solicitarLote',
      params: { tema: 'fracciones', nivel: '2eso', tipo: 'operacion', cantidad: 5 }
    }, '*');
  }
  if (ev.data?.type === 'BANCO_MATH_RESPONSE') {
    console.log('Ejercicios recibidos:', ev.data.ejercicios);
  }
});
